# Terms

Words the project uses in a fixed sense.

## Terms

- **Root node**: the dedicated main host appliance at an event, and the central composer and conductor.
  A full Linux machine (Raspberry Pi class or larger) with a USB host and physical MIDI inputs and outputs.
  An embedded root node is out of scope.
  See [architecture](../architecture.md#root-node).
- **Rendering node**: turns the bottom-layer language into sound, for example a MIDI instrument or a dough node.
- **dough**: a bottom-layer "machine language", parallel to MIDI.
